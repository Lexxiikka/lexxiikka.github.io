# Личная страница-визитка - [Lexxikka](https://lexxiikka.github.io/) (моя)

## ✨ Возможности

- **Загрузочный экран** - pre-load assets с индикацией прогресса
- **Анимированный профиль** - показ моих ников и цитат, а также анимации, в т.ч. при наведении мыши.
- **Музыкальный плеер** - 5 треков, которые выбирал лично я и выбирал с умом
- **Регулировка громкости** - отдельно для фоновой музыки и для плеера
- **Важные субтитры** - некоторые строки в музыке выделяются субтитрами, в оссобенности те, которые имеют важное или лорное значение
